## 🎯 Executive Overview

**Chekki AI** is a purpose-built AI homework grading and parent reporting platform designed specifically for South Korean English Kindergartens and after-school language academies (*hagwons*).

By integrating your academy’s weekly textbook curriculum and target vocabulary, Chekki AI autogrades student handwriting in 3 seconds and generates encouraging 1-click progress reports for parents, eliminating 5–10 hours of administrative overhead per teacher every month.

---

## 💡 The 3 Core Pain Points Chekki Solves

| Academy Pain Point | Traditional Method | Chekki AI Solution |
| :--- | :--- | :--- |
| **1. Answer Key Entry** | Teachers manually type weekly target vocab & answer keys (2–3 hrs/wk). | **3-Second Zero-Typing Upload**: Drop a textbook PDF/photo — AI extracts target vocabulary & ground-truth answer keys automatically. |
| **2. Home Practice Sync** | Teachers call or text parents individually to check homework progress. | **6-Digit Class Code Sync**: Parents enter a 6-letter class code once. Home scan mistake data syncs silently to the teacher dashboard. |
| **3. Monthly Parent Reports** | Teachers spend 5–10 hours/month writing manual student evaluations. | **1-Click Parent Growth Reports**: Chekki compiles home scan data into encouraging bilingual growth reports in 1 click. |

---

## 🛠️ How It Works (3-Step Teacher Workflow)

1. **Step 1: Set Up Class in 5 Seconds**  
   Create your class and share a 6-digit code (e.g. `POLY-6A`) with parents.
2. **Step 2: Upload Textbook PDF/Photo Once**  
   Drop this week's phonics & vocabulary chapter. Chekki's AI builds ground-truth answer keys with 99.9% precision.
3. **Step 3: Auto-Sync & Export Progress Reports**  
   Review red-bordered mistake items before class and export autogenerated PDF progress reports to parents in 1 click.
