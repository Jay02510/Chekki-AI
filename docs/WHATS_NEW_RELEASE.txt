What's New in Chekki AI (v1.2.2)

English:
- Visual Grading Status Indicators: Added clear color-coded statuses (red for mistakes, emerald green for correct answers) on worksheet items for a cleaner, intuitive overview.
- Dynamic Text Scaling: Long student answers and correct answers now automatically scale to fit the card layout perfectly without overlapping.
- Auth Persistence Improvements: Fixed session persistence state issues to ensure a reliable login experience when relaunching the app.
- Enhanced AI Analyze Performance: Added deterministic image caching and few-shot exemplars to the analyze endpoint, making grading analysis faster and more accurate.
- Restructured Bento Grid Layout: Refined the landing page layout into a clean 2:2:2 bento grid and optimized dark backgrounds for light mode.
- Friendly Copywriting & SEO: Refactored Korean landing page copy to a warm, friendly tone with keep-all line-wrapping, and integrated FAQ Schema (JSON-LD) markup for better SEO.
- Cross-Browser Video Loop Fixes: Improved the loading screen video playback loop compatibility across different browsers.

채키 AI 업데이트 소식 (v1.2.2)

한국어:
- 채점 상태 시각적 피드백 제공: 채점 완료된 항목들에 대해 직관적인 색상 피드백(오답은 빨간색, 정답은 에메랄드색 테두리 및 그림자)을 적용하여 한눈에 학습 현황을 볼 수 있습니다.
- 가독성을 위한 글자 크기 자동 조정: 아이의 답안이나 정답이 길어지는 경우 카드 레이아웃에 맞춰 폰트 크기가 자동으로 조절되어 가독성을 높였습니다.
- 로그인 세션 유지 및 안정화: 앱 재실행 시 로그인 정보가 끊기거나 동기화가 지연되는 현상을 수정하여 더욱 부드러운 시작 환경을 만들었습니다.
- AI 채점 성능 및 속도 향상: 분석(analyze) API에 이미지 캐싱 처리와 정교한 예시(Few-shot exemplars)들을 도입하여 분석 정확도와 속도를 획기적으로 개선했습니다.
- 랜딩 페이지 Bento Grid 개편: 홈 화면 레이아웃을 깔끔한 2:2:2 그리드로 재조정하고, 라이트 모드에서도 다크 백그라운드 디자인이 고급스럽게 보이도록 최적화했습니다.
- 친근하고 가독성 높은 한국어 문구: 랜딩 페이지 한국어 문구를 더욱 다정하고 따뜻한 "엄마의 마음" 톤으로 다듬고, 글자가 어색하게 잘리지 않도록 줄바꿈(keep-all) 설정을 추가했습니다.
- 웹 브라우저 비디오 루프 개선: 다양한 모바일/데스크톱 브라우저 환경에서 로딩 화면의 배경 비디오가 끊김 없이 매끄럽게 반복 재생되도록 호환성을 높였습니다.
- 검색 최적화(SEO) 강화: 웹 버전에 FAQ 구조화 데이터(JSON-LD Schema Markup)를 삽입하여 검색 노출 기회를 넓혔습니다.
