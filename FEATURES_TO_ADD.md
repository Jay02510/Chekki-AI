# 🚀 Chekki AI - Future Feature Roadmap

To evolve **Chekki AI** from a utility tool into a daily habit for Korean parents, we plan to implement the following features.

## 1. The "O-dap Note" (오답노트 - Mistake Review) 🌟 **(High Value)**
**Problem:** Checking homework is passive. Learning requires reviewing mistakes.
**Feature:** 
- Allow parents to flag questions as "Incorrect" manually or via AI detection.
- **Weekly PDF Generation:** Automatically compile all flagged questions into a printable "Weekend Review Sheet".
**Why:** It creates a personalized curriculum and tangible value beyond the screen.

## 2. Digital Sticker Board (Gamification) 🍬 **(Retention)**
**Problem:** Children need motivation to do homework.
**Feature:**
- **Chekki Stickers:** Every scan rewards a random digital sticker (Dinosaurs, Robots, Fruits).
- **Sticker Book:** A virtual album where children can place and collect stickers.
- **Unlockables:** Scan 10 times to unlock a printable Chekki Coloring Page.
**Why:** The child will ask the parent to use the app, driving retention.

## 3. "Clone My Worksheet" (AI Generation) 🪄 **(Pro)**
**Problem:** Once a worksheet is done, practice is over.
**Feature:**
- "Generate Similar Question" button.
- AI creates a *brand new* worksheet image with the same layout/style but different vocabulary words.
**Why:** Unlimited content generation makes the Pro subscription a no-brainer.

## 4. Enhanced Pronunciation Coach 🎤 **(Expansion)**
**Current Status:** Basic browser-based recognition implemented.
**Upgrade:**
- Use a dedicated Speech Evaluation API (e.g., Azure Speech or specialized ELSA-like API) for phoneme-level scoring.
- Give specific feedback (e.g., "Your 'R' sound needs work").

## 5. Community & Sharing 🤝
**Feature:** "Mom's Lounge"
- Share difficult worksheets or "O-dap Notes" with other parents.
- Weekly challenges ("3-Day Homework Streak").
